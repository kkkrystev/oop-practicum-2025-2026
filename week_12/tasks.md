## Задача 01 

### Class `Product`

Създайте клас `Product`, който моделира артикул в онлайн магазин. Всеки продукт има име, цена и уникален идентификатор.

Конструктори:
- Конструктор, който приема име и цена на продукта. Уникалният идентификатор се генерира автоматично при конструиране на обекта.

Функционалности:
- Достъп до името на продукта;
- Достъп до цената на продукта;
- Достъп до уникалния идентификатор на продукта.

### Class `ProductCatalog`

Създайте клас `ProductCatalog`, който съхранява колекция от продукти и предоставя възможност за тяхното търсене.

Функционалности:
- Добавяне на продукт към каталога;
- Търсене на продукт по име;
    - ако продуктът съществува, се връща указател към него;
    - ако продуктът не съществува, се връща `nullptr`.
    
### Class Template `StaticBuffer`

Създайте шаблонен клас `StaticBuffer`, който представлява фиксиран по размер контейнер за елементи.

Изисквания:
- Шаблонът приема type parameter `T` и non-type parameter `Capacity`;
- Съхранява елементи в статичен масив;
- Поддържа текущ размер;
- Не използва динамична памет.

Функционалности:
- Добавяне на елемент;
    - ако няма място в контейнера, добавянето не се изпълнява;
- Достъп до елемент по индекс;
- Връщане на текущ брой елементи;

### Class `Order`

Създайте клас `Order`, който моделира поръчка в онлайн магазин. Поръчката съдържа списък от избрани продукти и използва каталог, за да изчислява крайната цена. Всеки `Order` има уникален идентификатор.

Конструктори:
- Конструктор, който приема каталог с продукти.

Функционалности:
- Добавяне на продукт към поръчката по име;
    - ако продуктът не съществува в каталога, се игнорира;
- Изчисляване на общата цена на поръчката;
- Извеждане на съдържанието на поръчката;
- Извеждане на уникалния идентификатор на поръчката.

Допълнително:
- Поръчката трябва да реферира продуктите по подходящ начин;
- За съхранение на продуктите в поръчката трябва да се използва `StaticBuffer<Т, N>`.

## Задача 02 

### Class File

Създайте клас `File`, който моделира файл в система за обработка на документи. Всеки файл има име и съдържание.

Конструктори:
- Конструктор, който приема име и съдържание на файла.

Функционалности:
- Достъп до името на файла;
- Достъп до съдържанието на файла;
- Промяна на съдържанието на файла;
- Проверка дали файлът е празен.

### Class Logger

Създайте клас `Logger`, който моделира система за логване на събития.

Функционалности:
- Извеждане на съобщение в стандартния изход.

### Class FileService

Създайте клас `FileService`, който извършва обработка на файлове и съхранява история на всички извършени операции.

Конструктори:
- Конструктор, който приема обект от тип Logger&, който се използва за извеждане на съобщения за текущите операции.

Функционалности:
- `bool process(File& file)` - извършва обработка върху подаден файл;
    - ако съдържанието на файла е празно:
        1. записва съобщение в логера;
        1. записва в историята, че обработката е неуспешна;
        1. връща false;
    - ако съдържанието на файла не е празно:
        1. модифицира съдържанието на файла (например добавя префикс "[PROCESSED]");
        1. записва съобщение в логера;
        1. записва в историята, че обработката е успешна;
        1. връща true;
- Съхраняване на история на всички обработени файлове:
    - за всеки обработен файл се записва:
        - името на файла;
        - резултатът от обработката (SUCCESS / FAIL);
- `void printHistory() const` - извежда на екрана всички записи от историята в реда на обработване:
    - всеки запис съдържа *име на файл* и *статус на обработката*.

## Задача 03 

### Описание

В една система за поръчки клиентът може да плати по един от следните начини:

1. С карта
2. В брой
3. Чрез банков превод

Всеки вид плащане има различна информация, но всички плащания имат сума.

### Изисквания

Да се дефинират следните структури:

```cpp
struct CardPayment
{
    std::string cardNumber;
    double amount;
};
```

```cpp
struct CashPayment
{
    double amount;
};
```

```cpp
struct BankTransfer
{
    std::string iban;
    double amount;
};
```

След това да се дефинира тип:

```cpp
using Payment = std::variant<CardPayment, CashPayment, BankTransfer>;
```

### Клас `PaymentSystem`

Да се реализира клас:

```cpp
class PaymentSystem;
```

който съхранява множество плащания.

### Поле

Класът трябва да съдържа контейнер:

```cpp
std::vector<Payment> payments;
```

### Методи

#### 1. Добавяне на плащане

```cpp
void addPayment(const Payment& payment);
```

Методът добавя ново плащане в системата.

#### 2. Извеждане на всички плащания

```cpp
void printAll() const;
```

Методът извежда всички плащания в следния формат:

```txt
Card payment: ****1234, amount: 100
Cash payment, amount: 50
Bank transfer: BG12BANK0000, amount: 200
```

При плащане с карта не трябва да се извежда целият номер на картата, а само последните 4 цифри.

Пример:

```txt
1234567812349999
```

трябва да се изведе като:

```txt
****9999
```

#### 3. Обща сума на всички плащания

```cpp
double totalAmount() const;
```

Методът връща общата сума на всички плащания.

### 4. Обща сума по вид плащане

Да се реализират следните методи:

```cpp
double totalCard() const;
double totalCash() const;
double totalBank() const;
```

Те трябва да връщат общата сума съответно за:

- плащания с карта
- плащания в брой
- банкови преводи

### Пример за използване

```cpp
int main()
{
    PaymentSystem system;

    system.addPayment(CardPayment{"1234567812349999", 100});
    system.addPayment(CashPayment{50});
    system.addPayment(BankTransfer{"BG12BANK00000000", 200});
    system.addPayment(CardPayment{"1111222233334444", 75});

    system.printAll();

    std::cout << "Total: " << system.totalAmount() << std::endl;
    std::cout << "Card total: " << system.totalCard() << std::endl;
    std::cout << "Cash total: " << system.totalCash() << std::endl;
    std::cout << "Bank total: " << system.totalBank() << std::endl;
}
```

### Очакван изход

```txt
Card payment: ****9999, amount: 100
Cash payment, amount: 50
Bank transfer: BG12BANK00000000, amount: 200
Card payment: ****4444, amount: 75
Total: 425
Card total: 175
Cash total: 50
Bank total: 200
```
